* How it works

The general idea is to only install only the essential parts to access the private parts of my
configuration, and then let the nix-configuration scripts found there do the rest of the work.

To make this work, I need to have the following

- Install nix on the machine.
- Install tailscale and log in at my home-network.
- Access the nix definitions stored on my private forgejo servers and activate them.
